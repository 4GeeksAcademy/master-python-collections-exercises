# `007` Squares Dictionary

## 📝 Instructions:

1. Complete the function `squares_dictionary(n)`.

2. **Return** a dictionary where the keys are the numbers from `1` to `n` (both included) and each value is the square of its key.

## 📎 Example:

```py
print(squares_dictionary(5))
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

## 💡 Hints:

+ Start with an empty dictionary `{}` and add keys inside a `for` loop: `squares[number] = number ** 2`.

+ Bonus: try writing it in one line with a dictionary comprehension.
