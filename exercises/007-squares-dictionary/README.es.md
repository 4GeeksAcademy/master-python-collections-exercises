# `007` Diccionario de cuadrados

## 📝 Instrucciones:

1. Completa la función `squares_dictionary(n)`.

2. **Retorna** un diccionario cuyas claves son los números del `1` al `n` (ambos incluidos) y cada valor es el cuadrado de su clave.

## 📎 Ejemplo:

```py
print(squares_dictionary(5))
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

## 💡 Pistas:

+ Empieza con un diccionario vacío `{}` y añade claves dentro de un bucle `for`: `squares[number] = number ** 2`.

+ Extra: intenta escribirlo en una sola línea con un dictionary comprehension.
