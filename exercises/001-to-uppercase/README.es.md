# `001` A mayúsculas

Los strings traen muchos **métodos** incorporados: funciones que se llaman con un punto, como `text.lower()` o `text.strip()`.

## 📝 Instrucciones:

1. Completa la función `to_uppercase(text)`.

2. **Retorna** el mismo texto con todas las letras en mayúsculas.

## 📎 Ejemplo:

```py
print(to_uppercase("Hello world, practice makes perfect"))
# HELLO WORLD, PRACTICE MAKES PERFECT
```

## 💡 Pista:

+ Busca el método de strings que convierte el texto a mayúsculas.
