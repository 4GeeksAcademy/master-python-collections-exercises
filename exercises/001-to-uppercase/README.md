# `001` To Uppercase

Strings come with many built-in **methods**: functions you call with a dot, like `text.lower()` or `text.strip()`.

## 📝 Instructions:

1. Complete the function `to_uppercase(text)`.

2. **Return** the same text with every letter in uppercase.

## 📎 Example:

```py
print(to_uppercase("Hello world, practice makes perfect"))
# HELLO WORLD, PRACTICE MAKES PERFECT
```

## 💡 Hint:

+ Look for the string method that converts text to uppercase.
