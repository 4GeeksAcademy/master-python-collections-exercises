# `004` Contar mayúsculas y minúsculas

## 📝 Instrucciones:

1. Completa la función `count_upper_and_lower(text)`.

2. **Retorna** un diccionario con dos claves: `"uppercase"` y `"lowercase"`, con cuántas letras de cada tipo tiene el texto.

## 📎 Ejemplo:

```py
print(count_upper_and_lower("Hello world!"))
# {'uppercase': 1, 'lowercase': 9}
```

## 💡 Pista:

+ Es muy parecido al ejercicio anterior. Revisa los métodos `char.isupper()` y `char.islower()`.
