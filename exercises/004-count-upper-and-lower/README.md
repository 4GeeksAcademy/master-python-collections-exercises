# `004` Count Uppercase and Lowercase

## 📝 Instructions:

1. Complete the function `count_upper_and_lower(text)`.

2. **Return** a dictionary with two keys: `"uppercase"` and `"lowercase"`, with how many letters of each type the text has.

## 📎 Example:

```py
print(count_upper_and_lower("Hello world!"))
# {'uppercase': 1, 'lowercase': 9}
```

## 💡 Hint:

+ It's very similar to the previous exercise. Check the methods `char.isupper()` and `char.islower()`.
