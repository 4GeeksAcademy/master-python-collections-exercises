# `000` Welcome to Master Python: Strings and Collections

We are very excited to have you here! 🎉

In this LearnPack you will write functions that receive text or collections (lists, tuples, dictionaries and sets), transform them and **return** a new result.

## What will you practice?

- **Exercises:** `001-020`
- **Focus:** string methods, `split()` / `join()`, lists, tuples, dictionaries, sets, `*args`, list comprehensions, nested lists, parsing text and sorting with `sorted()` and `key`
- **Difficulty:** beginner to intermediate

## How to work on each exercise

1. Read the instructions.
2. Write your solution in `app.py`.
3. Click **Run** to see what your code prints.
4. Click **Test** and iterate until every test passes.
