## Instalación en un clic (recomendado)

Abre en [Codespaces](https://codespaces.new/?repo=4GeeksAcademy/master-python-collections-exercises) (recomendado) o [Gitpod](https://gitpod.io#https://github.com/4GeeksAcademy/master-python-collections-exercises).

> Cuando VS Code esté abierto, LearnPack debería iniciar automáticamente. Si no ocurre, ejecuta `learnpack start` en la terminal.

## Instalación local

1. Asegúrate de tener instalados [Node.js](https://nodejs.org) 18+ y [Python](https://www.python.org) 3.10+.

2. Instala LearnPack, el plugin de Python y las herramientas de testing:

```bash
npm i @learnpack/learnpack -g && learnpack plugins:install @learnpack/python
pip3 install pytest==6.2.5 pytest-testdox mock
```

3. Clona este repositorio e inicia los ejercicios:

```bash
git clone https://github.com/4GeeksAcademy/master-python-collections-exercises.git
cd master-python-collections-exercises
learnpack start
```

## ¿Qué vas a practicar?

- **Ejercicios:** `001-020`
- **Enfoque:** métodos de strings, `split()` / `join()`, listas, tuplas, diccionarios, sets, `*args`, list comprehensions, listas anidadas, interpretar texto y ordenar con `sorted()` y `key`
- **Dificultad:** principiante a intermedio

## ¿Cómo están organizados los ejercicios?

Cada carpeta de ejercicio contiene:

1. `README.md` / `README.es.md`: las instrucciones (inglés / español).
2. `app.py`: el archivo inicial donde escribes tu solución.
3. `test.py`: los tests de evaluación automática. No necesitas abrirlo, pero puedes leerlo si te atascas.

Haz clic en **Run** para ejecutar tu `app.py` y en **Test** para evaluarlo.
